# Aorus - Gaming Showcase Website

**Aorus - Gaming Showcase Website** is a gaming product showcase website developed using **HTML, JavaScript, and Bootstrap**.

The project focuses on presenting AORUS gaming products through a modern, immersive, and responsive interface while maintaining the brand's premium gaming identity.

## 🎮 About the Project

Aorus - Gaming Showcase Website was developed as a gaming-focused product presentation platform designed to showcase the AORUS ecosystem and its high-performance gaming components.

The website provides an engaging browsing experience by presenting various gaming products with structured layouts, interactive elements, responsive navigation, and optimized user interfaces across different screen sizes.

The showcased product categories include:

- Motherboards
- Graphics Cards
- Gaming Monitors
- Gaming Laptops
- Desktop PCs
- PC Peripherals
- Other PC Components
